MyQuran

Kebijakan Privasi

Berlaku sejak 25 September 2026 (menggantikan versi 22 September 2026)

MyQuran (sebelumnya bernama Ruang Tilawah) adalah aplikasi membaca, belajar, dan menghafal Al-Qur’an. Aplikasi ini gratis dan tidak berisi iklan. Halaman ini menjelaskan data apa yang digunakan aplikasi, untuk apa, dan bagaimana Anda mengendalikannya.

Ringkasnya

  • Membaca, belajar, hafalan, bookmark, target harian, dan riwayat baca bekerja tanpa akun dan tersimpan hanya di perangkat Anda.
  • Data dikirim ke server kami hanya jika Anda masuk dengan Google untuk sinkronisasi antar perangkat.
  • Tidak ada iklan, analitik, pelacakan, atau penjualan data.

Data di perangkat

Posisi terakhir dibaca, bookmark dan koleksinya, pengaturan tampilan, target harian, sesi baca (waktu mulai dan selesai, durasi aktif, tanggal, zona waktu, ayat terakhir), kemajuan belajar (tahap yang selesai, jawaban latihan, dan titik mulai yang Anda pilih), status hafalan dan jadwal murajaah, audio murottal serta terjemahan yang Anda unduh, rekaman bacaan Anda (lihat bagian mikrofon), serta sebuah ID perangkat acak yang tidak terkait identitas Anda. Data ini terhapus bila aplikasi dihapus.

Jika Anda masuk dengan Google

Untuk menyinkronkan data antar perangkat, aplikasi memakai Firebase Authentication dan Cloud Firestore dari Google. Yang disimpan:

  • Akun: ID pengguna Firebase, alamat email, dan nama akun Google (dikelola Firebase Authentication).
  • Sesi baca: waktu mulai dan selesai, durasi aktif, tanggal, zona waktu, ayat terakhir, dan ID perangkat acak.
  • Bookmark: nomor surah dan ayat, nama koleksi, serta waktu perubahan.

Data disimpan di Google Cloud wilayah Jakarta (asia-southeast2). Aturan akses server hanya mengizinkan pemilik akun membaca dan mengubah datanya sendiri. Data ini dipakai semata-mata untuk sinkronisasi; statistik dan streak dihitung di perangkat.

Mikrofon

Fitur “Rekam bacaanku” di sesi hafalan meminta izin mikrofon hanya ketika Anda memulai perekaman. Rekaman disimpan di perangkat saja dan tidak diunggah ke server mana pun. Rekaman ikut terhapus bila data aplikasi dibersihkan atau aplikasi dihapus.

Lokasi

Izin lokasi hanya dipakai saat halaman Kiblat dibuka untuk menghitung arah Ka’bah. Perhitungannya dilakukan di perangkat; lokasi tidak dikirim ke server. Jadwal salat memakai nama kota dan negara yang Anda pilih sendiri, bukan lokasi GPS.

Notifikasi

Pengingat salat dan tilawah dijadwalkan secara lokal di perangkat. Kontrol murottal tampil di notifikasi saat audio diputar.

Layanan pihak ketiga

  • Google (Firebase, Google Sign-In) untuk akun dan sinkronisasi, hanya jika Anda masuk.
  • AlAdhan API menerima nama kota dan negara yang Anda pilih untuk menghitung jadwal salat.
  • Islamic Network CDN (alquran.cloud), MP3Quran, dan equran.id menyediakan audio murottal saat Anda memutar atau mengunduhnya.
  • QuranEnc dan fawazahmed0/quran-api menyediakan terjemahan bahasa lain saat Anda mengunduhnya.
  • GDELT menyediakan daftar berita Islam berbahasa Indonesia.
  • Google Play memeriksa pembaruan untuk aplikasi yang dipasang dari Play Store. Versi APK dari GitHub Releases menanyakan versi terbaru ke GitHub.

Seperti semua layanan internet, penyedia di atas dapat melihat alamat IP perangkat saat permintaan dikirim. Teks Al-Qur’an (Tanzil) dan terjemahan Indonesia tersimpan di dalam aplikasi dan dibaca tanpa internet.

Anak-anak

Aplikasi ini tidak ditujukan khusus untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data pribadi anak. Masuk dengan Google bersifat opsional.

Kendali dan penghapusan

  • Keluar akun kapan saja di tab Saya › kartu profil › Keluar; data di perangkat tetap tersedia.
  • Hapus akun beserta seluruh data cloud di tab Saya › kartu profil › Hapus akun & data cloud. Penghapusan di server bersifat permanen.
  • Hapus data lokal dengan menghapus aplikasi atau membersihkan data aplikasi di pengaturan Android.

Keamanan

Semua komunikasi memakai HTTPS. Tidak ada kata sandi yang disimpan aplikasi; proses masuk ditangani Google.

Perubahan dan kontak

Perubahan kebijakan akan diumumkan di halaman ini dengan tanggal berlaku baru. Pertanyaan dapat diajukan melalui GitHub Issues.
