**Subjek:** Permohonan Izin Penggunaan API Audio equran.id untuk Aplikasi MyQuran (Proyek Pelajar, Nonkomersial)

Assalamu'alaikum warahmatullahi wabarakatuh.

Kepada Tim equran.id,

Terima kasih atas layanan equran.id yang sangat bermanfaat bagi umat.

Perkenalkan, saya Zainul Arkaan, pelajar [NAMA SEKOLAH]. Saya mengembangkan **MyQuran**,
aplikasi Android gratis untuk membaca, belajar, dan menghafal Al-Qur'an. Aplikasi ini
adalah proyek pribadi saya sebagai pelajar sekaligus bagian dari tugas sekolah. MyQuran
**nonkomersial**: tanpa iklan, tanpa pembelian dalam aplikasi, dan tanpa penjualan data.

**Penggunaan API equran.id (v2).** Aplikasi memakai audio murottal per ayat dan per surah
dari equran.id sebagai **sumber cadangan**, yaitu saat sumber utama tidak dapat dihubungi.
Audio diputar langsung dari server equran.id atas permintaan pengguna. Pengguna juga bisa
menyimpannya di HP sendiri untuk didengar tanpa internet. Kami tidak mengunggah ulang,
mengubah, atau mendistribusikan berkasnya.

Saya memohon izin penggunaan tersebut dengan **ketentuan** berikut:

- **Pasal 1 — Atribusi.** "equran.id" dan nama qari dicantumkan di halaman *Sumber & lisensi*.
- **Pasal 2 — Tanpa perubahan.** Rekaman tidak diubah, dipotong, atau digabung.
- **Pasal 3 — Tanpa distribusi ulang.** Tidak ada unggah ulang atau pembundelan audio di APK.
- **Pasal 4 — Pemakaian wajar.** Permintaan hanya terjadi saat pengguna memutar atau
  mengunduh. Tidak ada pengambilan massal.
- **Pasal 5 — Nonkomersial.** Aplikasi tetap gratis. Bila berubah, saya meminta izin baru lebih dahulu.
- **Pasal 6 — Pencabutan.** Bila diminta berhenti, sumber ini dihapus paling lambat 14 hari.
