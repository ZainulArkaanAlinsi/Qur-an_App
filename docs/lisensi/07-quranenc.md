Assalamu alaikum,

I am Zainul Arkaan, a student from Indonesia. I develop **MyQuran**, a free Android app for
reading, learning and memorizing the Qur'an. It is a personal and school project and is
non-commercial: no ads, no purchases, no sale of user data.

The app lets users download translations of the meanings of the Qur'an from the QuranEnc
API to their own phone and shows them unchanged, next to the Arabic text.

**We commit to:**

1. **No changes:** translations are shown exactly as published, never edited or shortened.
2. **Attribution:** "QuranEnc", the translation name, translator and version number are
   shown in the app.
3. **Updates:** we use the latest API version and refresh when a new one is released.
4. **Non-commercial:** the app stays free.
5. **Withdrawal:** the source is removed within 14 days if you ask.
